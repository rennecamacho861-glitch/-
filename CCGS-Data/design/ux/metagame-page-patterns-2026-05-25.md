# 局外大厅页面分区交互模式补充

状态：v0.9.3  
日期：2026-05-25  
关联规格：`CCGS-Data/design/ux/metagame-page-separation.md`

## Pattern: Metagame Page Tabs

- 局外大厅使用互斥页面，而不是在同一面板里同时展开主页、账号、地图、战备、商店和仓库。
- 页面导航固定为 `主页 / 账号 / 地图 / 战备 / 商店 / 仓库`，并在顶部保留金币、当前地图、入场费、战备值与仓库数量摘要。
- 主页只处理游戏目标、当前行动摘要和进入其他局外页面的主入口。
- 账号页只处理本地档案、属性教育、教程入口与未来账号 hook。
- 地图页只处理档位选择与风险说明。
- 战备页只处理进场清单和开始行动。
- 商店页只处理购买、价格和刷新。
- 仓库页只处理存放、带入和出售。
- 同页操作必须保持滚动位置，避免玩家在长商店或长仓库中每次点击后被拉回顶部。
- 切换到不同页面时可以回到新页面顶部，让页面切换有明确空间感。

## Pattern: Account Auth Hook Placeholder

- 账号和密码输入使用 `data-auth-hook` 与 `data-auth-field` 标记，供后续真实账号系统绑定。
- 当前版本登录/注册按钮必须禁用或明确标注为预留，不得暗示已经连接服务器、数据库或云存档。
- 账号 hook 不得直接修改 `ProfileState`；真实接入时应通过独立账号/存档端口同步，再交给局外 Profile 层读取。

## Pattern: Local Profile Summary Strip

- 页面顶部摘要只显示跨页面判断必须的信息：金币、地图、入场费、战备值、仓库数量。
- 摘要用于帮助玩家在不同页面切换时保持目标感，不承担详细操作。
- 摘要不得替代各页面正文中的详细说明和操作按钮。
