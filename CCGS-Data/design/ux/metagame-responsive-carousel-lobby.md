# UX Spec: Metagame Responsive Carousel Lobby

> **Status**: Implemented
> **Author**: Codex + ux-designer + ui-programmer
> **Last Updated**: 2026-05-26
> **Journey Phase(s)**: 局外准备、入场前决策
> **Template**: UX Spec

## Purpose & Player Need

大厅必须第一眼告诉玩家“这局去哪里、风险是什么、能不能出发”。地图选择不再是普通列表，而是大厅主舞台；商店、角色、背包和百科作为辅助入口围绕地图行动服务。

## Navigation Position

桌面端：左侧为地图轮播和入场检查，右侧竖向导航固定存在；竖栏顶部是“进入地图”，下方是五个局外入口。
手机端：顶部为账号资源条，中部为地图轮播，底部固定五入口导航：商城、角色、战斗、背包、百科。

## Layout Specification

### Desktop

- 顶部：本地档案、金币/属性档/背包/战备、当前地图。
- 主舞台：大地图卡片居中，上一张和下一张地图从左右背后露出，阴影表达层级关系。
- 右侧：进入地图按钮权重最高，其下为商城、角色、战斗、背包、百科。
- 入场检查：在地图主舞台旁显示入场费、敌人数值范围、掉落稀有度与当前带入物。

### Mobile

- 顶部：压缩为三段式账号和资源信息。
- 中部：地图轮播占主要高度，支持左右滑动。
- 下部：入场检查与开始行动按钮跟随地图内容。
- 底部：固定五入口导航，避免商城/背包等入口被长页面滚动埋住。

## Interaction Model

| Component | Mouse / Keyboard | Touch |
|---|---|---|
| 地图轮播 | 点击箭头、圆点、相邻地图卡；按钮可聚焦 | 左右滑动或点按箭头/圆点 |
| 进入地图 | 右侧首位按钮；行动页内也有开始行动按钮 | 行动页内大按钮，底部导航保持可达 |
| 道具详情 | hover / focus 展示 tooltip | 长按卡片展示 tooltip，释放后不触发购买/带入/出售 |
| 页面导航 | 右侧竖栏 | 底部固定栏 |

## Accessibility

- 地图卡、箭头、圆点和导航按钮均为真实 button。
- 当前页面使用 `aria-pressed` 标识。
- 地图可切换不仅依赖拖动，也提供按钮和圆点。
- 触屏长按是 hover 的补充，不移除键盘 focus tooltip。

## Acceptance Criteria

- [ ] 桌面大厅地图主视觉明显大于辅助入口。
- [ ] 手机端底部导航始终可见且不遮挡开始行动按钮。
- [ ] 长按 tooltip 不触发该卡片的主要操作。
- [ ] 地图轮播切换后顶部当前地图、入场费与战备上限同步更新。
- [ ] 仍由 `MetagamePort` 处理所有状态写入。
