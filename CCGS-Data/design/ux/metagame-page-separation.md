# 《照面之时》局外大厅页面分区 UX 规格

状态：v0.9.3 已实装  
日期：2026-05-25  
适用范围：局外账号档案、地图档位、战备、商店、仓库页面

## Overview

局外大厅从“一屏展示所有系统”改为六个明确页面：主页、账号、地图、战备、商店、仓库。目标是降低玩家首次进入时的认知负担，让“我现在是在理解目标 / 整理档案 / 选择风险 / 准备进场 / 买补给 / 管库存”这六件事有清晰边界。

## Player Fantasy

玩家应该感觉自己站在一次搜打撤行动前的临时据点里：先通过主页理解本局目标，再确认档案和属性，决定要去哪个危险档位，随后整理带入装备，最后从商店和仓库补齐构筑。页面切换像翻看战备终端的不同标签，而不是在同一个拥挤面板里找按钮。

## Detailed Rules

- 局外主面板保留顶部金币、当前地图、入场费、战备值和仓库数量摘要。
- 六个页面使用同一组导航按钮切换：主页、账号、地图、战备、商店、仓库。
- 主页显示游戏名、核心目标、行动摘要和进入战备/商店/地图/教程入口。
- 账号页显示本地档案 ID、账号/密码输入 hook、属性说明、重 Roll、升级与教程入口。
- 地图页只处理地图档位选择，展示入场费、战备上限、敌人数值区间和档位描述。
- 战备页只展示当前带入物品、入场状态和开始按钮，并提供跳转到仓库/地图的辅助按钮。
- 商店页只展示商店 offer、价格、战备值和刷新按钮。
- 仓库页只展示仓库物品、带入与出售操作。
- 商店、仓库、战备物品卡继续支持 hover/focus tooltip 显示道具规则、限制、经济信息与附魔效果。
- 点击购买、带入、卖出、撤下等同页操作时保留当前滚动位置；切换到另一个页面时允许回到新页面顶部。
- 账号/密码输入只作为后续账号系统 hook，不连接真实数据库，不改变本地存档逻辑。

## Formulas

本次不新增玩法公式。页面摘要读取既有局外状态：

- `属性总值 = spirit + intellect + strength + speed + constitution`
- `战备显示 = deploymentValue / selectedMapTier.deploymentValueCap`
- `仓库数量 = profile.stash.length`

## Edge Cases

- 金币不足或战备超限时，战备页开始按钮禁用，并通过状态标签显示不可进场。
- 仓库为空时，仓库页显示空状态文本，不渲染空列表。
- 战备为空时，战备页提示玩家去仓库带入物品，但仍允许空手进入满足条件的地图。
- 当前处于局内 run 时，局外大厅折叠为紧凑状态，不展示页面导航。
- 账号 hook 按钮禁用，避免玩家误以为已有远端登录能力。

## Dependencies

- `src/main.ts`：DOM HUD、局外页面渲染、页面切换、账号 hook 标记。
- `src/styles.css`：页面导航、分区布局、账号表单、移动端适配。
- `src/sim/metagame.ts`：局外状态真源，不由 HUD 直接改写。
- `CCGS-Data/project-docs/architecture/system-framework.md`：局外 Profile / Shop / Stash / Deployment 端口边界。

## Tuning Knobs

- 页面导航数量与排序：当前为账号、地图、战备、商店、仓库。
- 局外面板宽度：当前桌面为 `min(880px, calc(100vw - 384px))`。
- 商店/仓库 tooltip 宽度：当前最大约 340px。
- 移动端导航列数：当前为 2 列。

## Acceptance Criteria

- 局外大厅不再同时展示主页、账号、地图、战备、商店和仓库的完整内容。
- 玩家可以通过导航在六个页面间切换，并保留顶部状态摘要。
- 账号页存在账号和密码输入 hook，且登录/注册按钮明确为预留状态。
- 商店、仓库、战备物品 hover/focus 仍可查看道具详情。
- 同页购买/带入/出售后滚动位置不回到顶部。
- `npm run build` 通过，`npm test` 通过。
