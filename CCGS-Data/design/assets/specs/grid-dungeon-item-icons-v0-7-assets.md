## Shared Art Direction

All icons follow Art Bible §1-§8: light cyberpunk wasteland dungeon, old metal, dirty cloth, damaged brass, muted teal glass, amber utility glints, dim red warning accents only when the item implies danger. Icons must avoid pure white, labels, arrows, casino neon, and floating warning symbols. Each icon uses a centered object silhouette with enough padding for button and pickup-card use.
