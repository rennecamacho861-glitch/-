# Quick Design Spec: 开局装备、敌人密度与内战可见性

**Type**: Addition  
**System**: 开局构筑 / 敌人生态 / 反馈  
**GDD Reference**: `CCGS-Data/design/gdd/rulebook.md`  
**Date**: 2026-05-15

## Change Summary

本次新增一个极小的开局构筑选择，并把初始敌人数量从 10 名提高到 15 名。同步检查敌人内战触发条件，使玩家在局内更容易观察到敌人之间互相消耗、拾取遗物并成长。

## Motivation

当前玩家入局没有开局决策，且地图内 10 名敌人在较大迷宫中相遇概率偏低，敌人内战生态不明显。开局三选一让玩家立刻拥有构筑方向；提高敌人密度和扩大内战接触判定，让“大逃杀式敌人成长”更容易被玩家感知。

## Design Delta

当前 GDD 只规定玩家初始属性固定，未定义开局装备选择；初始地图固定 10 名 AI 单位。

本规格改为：

- 玩家每局开始时必须在 `回声针 / 手枪 / 绷带` 中选择 1 件开局装备。
- 开局装备选择不推进回合，不计入战利收益，不允许跳过。
- 初始 AI 单位数量调整为 15 名，仍全部使用普通敌人预算：五项属性总和 15。
- 远程武器不随敌人数量线性增加，避免手枪密度失控。
- 敌人内战从“相邻且可见”扩展为“距离 2 格内且至少一方可见或存在清晰视线”，每对敌人每回合最多自动结算一次。

## New Rules / Values

| Rule | Value |
|---|---|
| 开局装备池 | `echo`、`pistol`、`bandage` |
| 选择数量 | 3 选 1 |
| 是否可跳过 | 不可跳过 |
| 是否推进回合 | 否 |
| 是否增加 loot | 否 |
| 初始敌人数 | 15 |
| 普通敌人属性预算 | 总和 15，单项 1-6 |
| 内战接触距离 | 2 格内，且至少一方可见或存在清晰视线 |

## Affected Systems

| System | Impact | Action Required |
|---|---|---|
| Rulebook | 记录开局选择、敌人数量和内战触发 | 更新 v0.8.6 |
| Map Data | 初始敌人从 10 名扩到 15 名 | 更新 `createEnemies()` 与测试 |
| Simulation | 初始状态增加 `pendingPickupOffer = starter` | 不推进回合，不允许跳过 |
| Enemy Civil War | 提高触发可见性 | 调整 `canDuel()` |
| HUD | 开局三选一使用同一拾取面板 | starter 不显示跳过按钮 |

## Acceptance Criteria

- [ ] 新局开始时出现 `回声针 / 手枪 / 绷带` 三选一。
- [ ] 开局选择不推进回合、不增加 loot，且不能跳过。
- [ ] 初始地图生成 15 名敌人，ID 唯一，姓名稳定随机，属性预算合法。
- [ ] 初始手枪敌人数量仍受控，不因敌人数 1.5 倍直接增加远程密度。
- [ ] 敌人距离 2 格内且视线成立时会触发内战，双方 `combatCount` 增加并产生战损或击败。
- [ ] 内战胜者可拾取败者遗物并受敌人持有上限限制。
