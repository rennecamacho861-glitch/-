# Quick Design Spec: 局外大厅视觉优先级降权

**Type**: Tweak  
**System**: Game Shell & Product UI  
**GDD Reference**: `CCGS-Data/design/gdd/metagame-shell-product-ui.md`, `CCGS-Data/design/ux/metagame-responsive-carousel-lobby.md`  
**Date**: 2026-05-26

## Change Summary

在不重排局外大厅主结构的前提下，重新划分视觉优先级：地图轮播和开始行动保持最高权重；入场检查保留功能但压缩信息密度；右侧导航、顶部资源、底部摘要和装饰边框降权。

## Motivation

玩家反馈当前 UI 内容不多但显得杂乱。主要原因不是入口数量过多，而是地图、战备、导航、顶部资源、状态消息和装饰框都使用了近似强度的边框、发光、深色卡面和琥珀强调，导致没有明确视觉中心。此次调整让玩家第一眼知道“选地图并开始行动”，第二眼才处理“带了什么、还能去哪管理”。

## Design Delta

当前 GDD 要求：

> 主页是局外默认入口，也是行动配置主窗口，展示游戏名、核心目标、地图档位选择、当前战备清单和开始行动按钮。  
> 地图档位不再是独立页面，必须作为主页中最显眼的行动选择区呈现。  
> 战备清单不再是独立页面，必须作为主页中“入场检查”窗口呈现。

本规格补充为：

主页仍保留“顶部档案资源、地图主舞台、入场检查、右侧导航、底部摘要”的结构，但各区按以下权重显示：

1. **主行动层**：当前地图卡、地图切换、开始行动按钮。允许使用最高亮度、最大标题和最强边框。
2. **决策辅助层**：入场费、敌人区间、战备值、掉落档位、携带物概览。只显示能直接影响“是否进场”的摘要，不展开完整物品列表。
3. **管理入口层**：商店、角色、背包、百科、训练教程。保持可点击，但视觉上弱于开始行动。
4. **背景信息层**：顶部金币、属性档、仓库数、当前地图摘要、上局记录、目标提示。使用低对比小字号或轻量卡片。
5. **装饰层**：旧金属边框、网格、框体贴图、分隔条。不得与主行动层抢占注意力。

## New Rules / Values

- 行动主页中，地图选择消息如“已选择二档”不再作为全宽高亮条常驻；地图卡自身承担选中反馈。
- 入场检查中的携带物改为紧凑摘要：显示携带数量、战备值、失败风险和最多 3 个物品预览；完整携带管理留给背包/仓库入口。
- 底部摘要仍保留四块结构，但改为低权重信息条，不再像主操作卡一样发光或重边框。
- 右侧导航保留当前入口数量和顺序，但只有“开始行动”使用强 CTA；其他入口以弱边框、短高度和低饱和背景呈现。
- 地图轮播相邻地图只作为层级暗示；隐藏或弱化其细节标签，避免与当前地图竞争。
- 顶部资源条只做状态确认，不使用与主 CTA 同等级别的琥珀发光。

## Affected Systems

| System | Impact | Action Required |
|---|---|---|
| Game Shell & Product UI | 视觉层级和信息密度调整 | 更新 `src/main.ts` 局外主页标记与 `src/styles.css` |
| Metagame Economy | 无规则变化 | 无 |
| Item System | 物品 tooltip 保持来源不变 | 紧凑携带预览继续复用现有 tooltip |
| HUD & Combat UI | 无局内 HUD 变化 | 无 |

## Acceptance Criteria

- [ ] 行动主页第一视觉焦点是当前地图卡与开始行动，而不是顶部资源条、右侧导航或底部摘要。
- [ ] 入场检查仍能看出入场费、敌人区间、掉落档、战备值、携带数量和失败风险。
- [ ] 携带物完整清单不再在行动主页常驻展开；玩家可通过“调整背包”进入管理。
- [ ] 商店、角色、战斗、背包、百科入口仍可点击，并且当前页仍有视觉高亮。
- [ ] 桌面和移动端布局不互相遮挡，地图主舞台仍大于辅助入口。
- [ ] `npm run build` 与 `npm test` 通过。

## GDD Update Required?

No. 本轮是既有 Game Shell & Product UI 的表现层降权补充，不改变局外经济、地图档位、战备或入场规则。
