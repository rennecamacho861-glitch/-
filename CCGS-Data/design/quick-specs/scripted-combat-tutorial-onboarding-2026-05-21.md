# Quick Design Spec: 脚本化战斗教学与新手开局顺序

**Type**: Addition  
**System**: Tutorial Onboarding / Encounter Combat / HUD & Combat UI  
**GDD Reference**: `CCGS-Data/design/gdd/rulebook.md`、`CCGS-Data/design/gdd/combat-system.md`  
**Date**: 2026-05-21

## Change Summary

将当前“按场景弹说明”的新手教程扩展为一段可选择进入的脚本化训练流程。玩家点击“需要新手教程”后，先进入教程场景，在玩家 5 格内生成 2 名属性总值为 10 的教学敌人，并用固定动作脚本教学防御、情报、优势、攻击方向、闪避、优势投入、击杀和说服；完成后再进入正式开局四选一。

## Motivation

玩家反馈战斗流程中不清楚每个行为的意义，也不理解情报的收益。尤其是防御看似“少挨打”，但它真实的价值是读出属性、道具或攻击方向；优势看似只是一个提示，但 v0.8.16 后已经成为可积累、可支付的资源。普通文字说明无法让玩家体验“先读再打”的决策链，所以需要用固定敌人和固定动作让玩家实际走一遍。

## Design Delta

当前 GDD 说（`rulebook.md`，新手教程）：

> 选择“需要”后，教程在本次页面会话中按场景触发，单条教学只显示一次。  
> 教程弹窗只属于 HUD 表现层，不写入 `GameState`，不影响模拟层规则和 seed 复现。

本规格改为：

选择“需要”后，游戏先进入 `tutorialScenario`，由模拟层生成独立训练场和 2 名固定教学敌人。HUD/localStorage 仍只保存教程偏好和已读弹窗；但教学敌人、固定动作脚本、教程步骤、输入允许列表、检查点恢复和“教程完成后再开局四选一”的流程必须由模拟层拥有。教程场景不产生正式收益，不进入正式局的 seed 掉落、敌人成长、空投或毒圈循环。

## New Rules / Values

### Tutorial Flow

1. 首次进入页面仍弹出“是否需要新手教程”。
2. 选择“不需要”：直接进入正式开局四选一。
3. 选择“需要”：进入训练场景，暂缓正式开局四选一。
4. 训练场景在玩家 5 格内生成 2 名教学敌人，敌人不可掉落正式道具，不参与随机拾取成长。
5. 完成第二名敌人说服教学后，结束训练场景，重置玩家生命与负面状态，再弹出正式开局四选一。

### Tutorial Enemy 1: 高伤低血敌人

目的：教学“防御不是拖延，而是读取情报并拿优势；攻击前要先看速度/攻击方向。”

建议配置：

| 字段 | 值 |
|---|---|
| 名称 | 裂刃拾荒者 |
| 属性总值 | 10 |
| 精神 | 1 |
| 智力 | 1 |
| 力量 | 5 |
| 速度 | 2 |
| 体质 | 1 |
| 教学装备 | 教学长刀，不掉落；用于保证第一次无防护命中能演示高伤/重伤风险 |
| 固定动作 | 攻击 -> 攻击 -> 攻击 -> 防御或虚弱 |
| 固定攻击方向 | 左 -> 右 -> 左 |

脚本步骤：

1. 首次照面弹窗说明：敌人力量高、体质低，直接莽攻有机会击杀，但如果不知道速度和方向，会被先手或重伤。
2. 第一回合高亮“防御”，建议玩家选择防御。敌人固定攻击。有效防御后玩家获得 1 点优势和至少 2 条情报，优先显示 `体质 = 1` 与一条攻击/速度相关信息。
3. 弹窗解释：`体质 = 1` 意味着敌人最大生命和重伤阈值都低，之后可用攻击兑现；优势点可用于逃跑、说服、续战或部分优势道具。
4. 若玩家在读出方向前选择攻击，教学敌人按固定攻击先手结算并演示高伤/重伤风险；该演示不带入正式开局，弹窗解释“双方攻击时速度更快者先命中；若先手伤害造成重伤，后手攻击可能丢失”。随后回到教学检查点。
5. 第二个教学动作再次高亮“防御”，敌人固定攻击。有效防御后优先给予下一次攻击方向情报，例如 `下次攻击方向 = 右`。
6. 弹窗解释：攻击方向是确认情报，只对下一次真实攻击有效，正确方向躲闪胜率显著高于乱猜。
7. 下一回合高亮对应方向躲闪。敌人固定攻击，玩家正确躲闪成功，并获得 2 点优势。
8. 弹窗提示玩家当前共有 3 点优势，并引导将 3 点优势全部投入速度。每次支付 1 点优势选择 `pressTempo`，直到下一动作回合速度修正累计到 +3。
9. 最后一回合高亮“进攻”。玩家进攻，凭速度投入拿到先手并重伤敌人；下一次进攻完成击杀。

### Tutorial Enemy 2: 低智力说服敌人

目的：教学“不是每个敌人都要杀；情报也能服务说服。”

建议配置：

| 字段 | 值 |
|---|---|
| 名称 | 惊惧拾荒者 |
| 属性总值 | 10 |
| 精神 | 2 |
| 智力 | 1 |
| 力量 | 2 |
| 速度 | 2 |
| 体质 | 3 |
| 教学装备 | 无，或携带低价值消耗品但不掉落 |
| 固定动作 | 攻击或防御 -> 防御/迟疑 |
| 固定攻击方向 | 左 |

脚本步骤：

1. 照面弹窗说明：这个敌人的智力很低，若你有优势和相关情报，说服比硬打更稳。
2. 第一回合引导防御或正确闪避，敌人固定低伤攻击，玩家获得 1 点优势并优先读出 `智力 = 1`。
3. 弹窗解释：智力低代表更容易被说服；说服值受玩家智力、有效情报、支付修正、道具修正和局势影响。
4. 高亮“说服”。玩家支付 1 点优势进行说服并成功，敌人进入停战/合作状态。
5. 弹窗总结：击败、逃跑、说服都是照面的出口。完成后进入正式开局四选一。

### Tutorial Constraints

- 教学敌人必须在模拟层生成，不能只在 HUD 文案中伪造。
- 教学动作脚本必须可复现，不读取普通 AI 权重。
- 教程允许为了教学安全使用检查点恢复：演示受伤/重伤后可以还原到上一教学步骤；正式局不得使用该机制。
- 教程场景不触发正式局敌人成长、道具节点拾取、掉落、空投、毒圈和撤离收益。
- 教程弹窗可以阻塞输入，但必须始终提供“跳过教程”按钮；跳过后直接进入正式开局四选一。
- 如果玩家选择“不需要”，本地保存关闭偏好，后续不再弹出教学。

## Acceptance Criteria

- [ ] 首次进入游戏时仍询问是否需要新手教程。
- [ ] 选择“不需要”后直接进入正式开局四选一，后续不再弹教程。
- [ ] 选择“需要”后先进入训练场景，正式开局四选一被延后到教程完成后。
- [ ] 训练场景在玩家 5 格内生成 2 名属性总值为 10 的教学敌人。
- [ ] 教学敌人使用固定动作脚本和固定攻击方向，不走普通 AI 权重。
- [ ] 第一名敌人教学防御、体质情报、速度/重伤风险、方向情报、正确躲闪、3 点优势投入速度、攻击击杀。
- [ ] 第二名敌人教学低智力目标、优势支付说服和停战出口。
- [ ] 教学演示造成的伤害、重伤、状态和敌人掉落不带入正式开局。
- [ ] 任意教学弹窗都可跳过教程，跳过后进入正式开局四选一。
- [ ] No regression：正式局的普通敌人生成、开局四选一、照面战斗、掉落和构建测试不受教程脚本影响。

## Open Questions

- 第一名敌人要求“属性总值 10”且要同时展示高速度、高伤害、重伤风险。按现有属性范围和伤害公式，单靠总值 10 很难稳定做到“高速 + 高伤 + 重伤”。本规格建议用不掉落的教学长刀或教程检查点演示来保证教学效果；实装前可选择改为属性总值 12，或允许教学装备参与演示。
