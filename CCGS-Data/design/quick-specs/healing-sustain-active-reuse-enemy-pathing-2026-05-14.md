# Quick Design Spec: 治疗续航、主动道具复用与敌人移动修复

**Type**: Addition + Tweak  
**System**: Item System / Enemy AI / Map & Exploration  
**GDD Reference**: `CCGS-Data/design/gdd/rulebook.md`  
**Date**: 2026-05-14

## Change Summary

补充一批能给予回血或止损的道具，缓解当前战损不可控的问题；修正主动道具默认“一次性”的实现偏差；将敌人迷宫移动从贪心一步改为基于边缘墙的可达寻路，避免复杂迷宫里卡住。

## Motivation

当前版本的治疗资源过少，玩家在数次照面或远程先手后很难把局面拉回可玩区间。与此同时，道具模板规则已经规定“同一件道具同回合只能手动使用一次，不同道具可连续使用”，但代码默认把未标次数的主动道具消耗掉，削弱了构筑意义。敌人移动虽然存在，但在无死路编织迷宫里使用局部贪心，遇到墙线绕路时经常停住，无法形成与玩家争夺拾取点的压力。

## New Rules / Values

1. 主动道具默认 `usage.mode = "unlimited"`，`manualLock = "per-round"`；只有标明固定次数、弹药、破碎、投掷、支付或布置消耗的道具才消耗次数或移除。
2. 场外手动道具成功使用后视为玩家行动，推进 1 回合并触发敌人移动；拾取三选一仍不推进回合。
3. 新增 8 件治疗/止损道具：

| ItemId | 稀有度 | 端口 | 效果 | 限制与反制 |
|---|---|---|---|---|
| `salve-tin` | common | 战斗/场外手动 | 回复 1 生命 | 同回合同实例只能用一次；场外使用推进回合 |
| `field-ration` | common | 场外手动，2 次 | 回复 2 生命 | 不可在战斗中使用；使用推进回合 |
| `charcoal-tablet` | common | 战斗/场外手动，2 次 | 清除中毒并回复 1 生命 | 无中毒时只提供小回复 |
| `pressure-bandage` | uncommon | 优势窗口手动 | 回复 3 生命并关闭本次优势窗口 | 必须先取得优势；不能防止已经归零 |
| `heat-pad` | uncommon | 战斗手动 | 回复 1 生命，下一次受伤 -1 | 只保护一次；远程与近战都可消耗 |
| `blood-sponge` | uncommon | 战斗手动 | 下一次近战命中后自身回复 1 生命 | 躲闪、防御拖延或远程对抗可让它落空 |
| `mercy-thread` | common | 成功躲闪条件触发 | 每场照面首次成功躲闪后回复 1 生命 | 敌人不攻击、方向判断失败或远程压制会降低触发率 |
| `emergency-syringe` | rare | 受到重伤/濒危条件触发 | 每局一次，生命未归零且降到重伤阈值内时回复 4 生命，然后破碎 | 爆发伤害直接归零时无法挽救；破碎后不掉落 |

4. 敌人每次玩家行动后获得 1 次移动机会；追击、寻物和巡逻都必须使用与玩家相同的边缘墙阻挡、单位占位和毒圈规避规则。目标可达但直线被墙挡住时，敌人应沿最短可达路径走出第一步。

## Acceptance Criteria

- [ ] 道具池总数从 65 增加到 73。
- [ ] 未标固定次数的主动道具使用后不从背包移除，但同一实例同回合不能重复手动使用。
- [ ] 标固定次数、弹药、投掷、布置、支付的道具仍能正确消耗或移除。
- [ ] 玩家和敌人都能使用新增治疗道具；敌人低血量时会优先考虑治疗。
- [ ] 敌人在复杂边缘墙迷宫中能沿可达路径追击、寻物或巡逻。
- [ ] `npm test` 与 `npm run build` 通过。
