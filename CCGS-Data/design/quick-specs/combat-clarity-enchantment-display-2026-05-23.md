# Quick Design Spec: 战斗判定解释与附魔展示清晰化

**Type**: Tweak + Addition  
**System**: 战斗 / HUD 道具展示 / 附魔实例  
**GDD Reference**: `CCGS-Data/design/gdd/rulebook.md`、`CCGS-Data/design/gdd/combat-system.md`  
**Date**: 2026-05-23

## Change Summary

本次 P0 更新修正两个玩家困惑点：低伤攻击被防御减免后没有给优势，以及正确方向闪避失败时没有说明概率原因。同时补齐附魔实例在道具介绍中的效果文本和边框特效。

## Motivation

玩家已经学习到“防御能读情报并拿优势”“正确方向闪避能反制攻击”。当系统内部因为低伤阈值、枪线、防御未减伤、重伤压制或闪避概率导致结果不符合直觉时，若没有立即解释，玩家会误以为规则失效。附魔道具只显示附魔名前缀也会让玩家无法判断它真正改变了什么。

## Design Delta

当前 GDD 写法中，有效防御要求“防御至少减少 2 点伤害”。运行时低力量攻击的基础伤害常为 2，防御后只减 1 点，因此会产生“明明防御了攻击却没拿优势”的体验断层。

本次改为：

- 只要本回合确实承受敌方攻击、远程、投掷或压制动作，防御后未被重伤，并且防御至少减少 1 点伤害，即视为有效防御。
- 防御未形成优势时必须弹出教学反馈，说明失败原因：未实际减免、远程枪线不吃普通防御、或伤害仍形成重伤。
- 正确方向闪避仍不是 100% 命中反制；若玩家读向正确但概率判定失败，必须弹出教学反馈，显示本次闪避率，并说明速度差、道具修正和状态会影响结果。
- 附魔道具在背包/道具介绍中必须显示附魔效果文本，效果描述按 `HIT / PRIME / COUNTER / SUPPORT / TRAP / AMMO` 模板匹配真实生效端口。
- 附魔实例必须在 HUD 中拥有区别于稀有度的附魔边框/辉光；颜色与附魔类型一致，但文本说明仍是主要信息。

## New Rules / Values

| 参数 | 旧值 | 新值 |
|---|---:|---:|
| 有效防御最低减伤 | 2 | 1 |
| 正确方向闪避基础率 | 75% | 不变 |
| 正确方向闪避上下限 | 55%-95% | 不变 |
| 防御未得优势提示 | 无 | 触发教学反馈 |
| 正确方向闪避失败提示 | 无 | 触发教学反馈 |

附魔介绍模板：

- `HIT`：该道具直接命中并造成伤害时，追加附魔效果。
- `PRIME`：该道具强化下一次攻击；该攻击命中时追加附魔效果。
- `COUNTER`：该道具的反应条件成立时，将附魔效果作用到触发者或当前敌人。
- `SUPPORT`：原效果成功后获得一次附魔预备，下一次有效命中消耗并追加附魔效果。
- `TRAP`：布置时不触发；敌人踩中或触发地物时追加附魔效果。
- `AMMO`：补充成功后，下一发有效子弹承载附魔效果。

## Acceptance Criteria

- [ ] 低力量敌人攻击被防御减免 1 点时，玩家获得有效防御优势。
- [ ] 玩家防御枪线或仍被重伤时，若未获得优势，会出现解释性教学反馈。
- [ ] 玩家选择正确闪避方向但概率判定失败时，会出现解释性教学反馈并显示本次闪避率。
- [ ] 附魔道具 tooltip 显示附魔类型、承载模板和具体效果。
- [ ] 附魔道具在背包中有附魔边框特效，且不依赖颜色传达规则。
- [ ] `npm test` 与 `npm run build` 通过。

## GDD Update Required?

Yes。更新 `combat-system.md` 与 `rulebook.md`：有效防御最低减伤改为 1 点；补充“正确方向闪避失败”和“防御未形成优势”的确认式教学反馈；补充附魔道具介绍必须展示具体附魔效果。
