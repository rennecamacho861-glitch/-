# Quick Design Spec: 橙色局外道具与掉落经济重调

**Type**: Addition + Tuning  
**System**: Item System / Enemy AI / Loot Economy / HUD Feedback  
**GDD Reference**: `CCGS-Data/design/gdd/rulebook.md` - 第 12 章道具系统、第 13 章敌人成长  
**Date**: 2026-05-19

## Change Summary

橙色 `rare` 道具从“低次数的一次性强道具”调整为“高价值、可反复使用但消耗时间或承担中断风险的局内资产”。回声针和绷带改为无限使用但每次花费 1 回合；旧弹夹改为无限换弹工具，但一次换弹需要 2 回合，期间若进入战斗则换弹失败。

同时大幅下调橙色道具从敌人身上掉落的概率，并加入每局同一 `rare` 物品最多出现 2 个的全局生成上限，避免玩家通过敌人成长和掉落滚出过量橙色装备。

## Motivation

当前回声针、绷带和信号类橙色道具因 1 次限制而不像橙色稀有度，尤其开局三选一时会显得“看起来珍贵，实际很抠”。将它们改为无限使用后，玩家会获得更明确的长期布局感；但每次使用都会消耗行动回合，让敌人移动、拾取、逼近或触发遭遇，形成搜打撤所需的赌局压力。

## Design Delta

Current GDD says (`rulebook.md`, 12.4 / 12.6):

> 绷带：战斗外回复 3 点生命。  
> 回声针：释放扩散声波，锁定最近未清空道具节点或 AI 所在的 2x2 四格回响区。  
> 旧弹夹：给手枪 +2 发，最多补到 5 发。  
> 若敌人存在可掉落装备，至少掉落 1 件；其余装备按 35% 独立检定。

This spec changes that to:

- 绷带：无限使用；每次成功治疗回复 3 生命并花费 1 探索回合；满血时不能使用，不花费回合。
- 回声针：无限使用；每次标出最近未清空道具节点或 AI 所在的 2x2 回响区，并花费 1 探索回合。
- 旧弹夹：无限使用；一次换弹花费 2 探索回合；第 1 回合弹出“换弹中”确认反馈，第 2 回合若未被拉入战斗则给手枪 +2 发，最多到 5；若中途进入战斗，换弹失败，不补弹。
- 橙色掉落：`rare` 不参与保底掉落；每件 `rare` 装备独立 8% 掉落，且不受 35% 普通掉落检定影响。
- 每局同一 `rare` `ItemId` 从生成到掉落最多出现 2 个；开局三选一中的回声针、手枪、绷带各计入 1 次出现。

## New Rules / Values

| Parameter | Old Value | New Value | Rationale |
|---|---:|---:|---|
| 回声针使用次数 | 1 次 | 无限，成功使用花费 1 回合 | 橙色侦察道具成为长期布局工具，但会让敌人行动。 |
| 绷带使用次数 | 1 次 | 无限，成功治疗花费 1 回合 | 橙色治疗道具成为撤退/续航资产，但用得越多越拖节奏。 |
| 旧弹夹使用次数 | 1 次 | 无限，换弹花费 2 回合 | 手枪构筑可持续，但换弹期间被照面会失败。 |
| 旧弹夹补弹量 | +2，最多到 5 | +2，最多到 5 | 保持单次收益，强化的是可重复尝试与风险。 |
| rare 掉落保底 | 可被保底选中 | 不参与保底 | 避免击败高价值敌人稳定获得橙色装备。 |
| rare 独立掉落率 | 35% 或保底 | 8% | 大幅降低橙色装备从敌人链式转移到玩家的概率。 |
| 同一 rare 每局出现上限 | 无 | 2 个 | 限制同物品堆叠和重复刷出。 |

## Acceptance Criteria

- [ ] 回声针和绷带没有 charges，成功使用时推进 1 探索回合并生成确认式反馈。
- [ ] 满血使用绷带不会生效，也不会推进回合。
- [ ] 旧弹夹没有 charges；使用后进入 2 回合换弹流程，完成时手枪 +2 发且不超过 5。
- [ ] 换弹流程中任意时点进入照面，换弹失败，不增加弹药，并生成失败反馈。
- [ ] `rare` 道具不参与敌人掉落保底；每件 `rare` 独立 8% 掉落。
- [ ] 同一 `rare` `ItemId` 每局从开局 offer、敌人出生、地图/空投 offer 到掉落可见出现次数不超过 2。
- [ ] 非 `rare` 掉落仍保留可感知收益：有非 rare 候选时保底 1 件，其余按 35% 检定，默认最多 2 件，5% 额外 1 件。
- [ ] No regression：拾取三选一、敌人拾取成长、手枪弹药上限、HUD 道具文案和现有战斗测试继续通过。

## Implementation Status - 2026-05-20

状态：已实装并通过验证。

- `echo`、`bandage`、`old-magazine` 已改为 `usage.mode = "unlimited"`，背包不再显示剩余次数。
- `echo` 与 `bandage` 成功使用会推进 1 个探索回合，并通过 `FeedbackEvent` 弹出确认式反馈。
- `old-magazine` 已改为战斗外 2 回合换弹；任一换弹回合后进入照面都会失败且不补弹。
- `rare` 掉落已从保底中剥离，每件 rare 候选独立 8% 检定；非 rare 仍保底 1 件并保留 35% 补充掉落。
- 地图生成已维护 `rareItemAppearances`，开局三选一、敌人初始携带与 LootNode offer 共享同一 rare 同物品上限 2。
- 验证：`npm test` 115/115 通过；`npm run build` 通过。
