# 《照面之时》游戏概念

## Overview

《照面之时》是一款 5-10 分钟一局的俯视角黑暗迷宫搜打撤原型。玩家在有限视野中搜寻道具和战利，判断继续深入或撤离；遇到敌人时进入短促的照面战斗。核心不是长时间消耗，而是视野、信息、属性和动作选择交织出的几回合博弈。

## Player Fantasy

玩家像在一场危险赌局里摸牌、下注和离桌：先看见对手、读出对手、带着合适道具进入照面，就能把短促战斗变成自己掌控的局；信息不足时，每一步都像在黑暗中押注。

## Core Pillars

- 视野领先：谁先看见谁，谁就可能获得开局优势。
- 信息博弈：知道敌人的属性、道具和倾向，比单纯数值更重要。
- 短促照面：战斗应在少数动作内给出结果或新选择。
- 长线程布局：探索、道具、敌人成长、毒圈/空投和撤离共同形成局内策略。

## MVP Definition

- 俯视角格子迷宫与有限视野。
- 道具节点和三选一随机道具。
- 敌人巡逻、视野、信息和照面触发。
- 基于精神、智力、力量、速度、体质的战斗框架。
- 进攻、防御、躲闪、优势窗口、逃跑和说服。
- 至少一轮可完成的搜打撤闭环。

## v0.6.2 World Tone Candidate

默认世界观调整为废土朋克：玩家是旧城废墟中的拾荒者，进入一座封存地下回收区，在断电管廊、旧地堡、废料堆、红光警戒线和污染带之间寻找可用物，并在撤离前判断是否继续深入。

“照面”保留为核心体验，指双方在拐角、灯光、枪口或红光报警中同时暴露的瞬间。赌博体验保留，但改写为废土语境里的赌命、押注和离场，而不是现代赌场意象。

玩家可见文本优先使用“废墟管廊 / 封存区 / 地堡回收区”“拾荒点 / 货箱 / 废料堆”“热度 / 警戒”“闸门 / 撤离井 / 外环出口”等词。具体道具命名以 `CCGS-Data/design/gdd/rulebook.md` 第 24 章为准。
