# v0.8.14 全道具六附魔穷举表

状态：规则草案，等待确认  
关联真源：`rulebook.md` 第 12.3.4、24E 章；`enchantment-authoring-matrix-v0-8-14.md`  
用途：把当前 134 件可拾取道具对 6 种附魔的结果全部展开，作为后续代码、UI 文案和 QA 用例的对照表。

## 阅读规则

- 每个 `ItemId` 只能拥有 1 个附魔，但本表列出它分别获得六种附魔时的写法。
- 本表共有 `134 × 6 = 804` 个道具附魔组合。
- `enchantPower = max(1, min(3, floor(eligiblePayloadAmount)))`；极寒使用 `ceil(enchantPower / 2)`。
- `SUPPORT` 不直接伤害敌人，只在原效果成功后刷新 1 个不叠加的下一次有效攻击预备。
- `TRAP` 只在敌人实际触发布置物时生效。
- `AMMO` 只影响补充成功后的下一发有效子弹或远程攻击。

## 难适配道具微调

| 类型 | 代表物件 | 微调规则 |
|---|---|---|
| 治疗与续航类 | 绷带、药膏铁盒、压缩口粮、压伤绷带、急救针等 | 不把治疗转化为即时伤害；治疗成功后只刷新 1 个不叠加的 SUPPORT 预备。 |
| 情报类 | 回声针、信号镜、折叠地图、记事本、读片类 | 情报照常只显示结构化信息；情报成功后刷新 SUPPORT 预备。 |
| 视野与隐蔽类 | 照明棒、信号火、黑布、偏光片、冷却气囊等 | 视野、隐蔽或抗惩罚效果成功后刷新 SUPPORT 预备；不会直接隔墙伤害敌人。 |
| 移动、逃跑、说服与支付类 | 跑绳结、假声哨、标记硬币、髓币、逃生计数绳等 | 动作或支付判定完成后刷新 SUPPORT 预备；失败则不刷新。 |
| 陷阱与布置物 | 陷阱、铜铃线、铁蒺藜、绊线卷等 | 布置时不触发附魔；敌人实际踩中、报警或受伤时才触发 TRAP 附魔。 |
| 弹药与补充类 | 旧弹夹 | 换弹成功后，下一发有效子弹携带附魔；换弹期间被拉入战斗则换弹失败且没有附魔弹。 |
| 无伤害反应类 | 护臂、软底鞋、稳心符、眼镜、部分读片 | 反应条件成立时按 COUNTER 或 SUPPORT 生效；不凭空造成独立伤害。 |
