# 局外大厅 UI 美术补充

状态：v0.9.3  
日期：2026-05-25  
关联：`CCGS-Data/design/art/art-bible.md`、`CCGS-Data/design/ux/metagame-page-separation.md`

## Visual Role

局外大厅是“行动前的废土战备终端”，视觉上要和迷宫 HUD 同源，但信息密度更像据点里的旧设备面板：暗底、旧金属边、琥珀高亮、暗青状态光、少量暗红风险提示。

## Page Identity

- 账号页：偏档案终端，强调本地档案 ID、属性块和账号 hook 输入框。
- 主页：偏废土战备终端开机屏，强调游戏名、搜打撤目标和进入战备的主按钮。
- 地图页：偏风险选择板，地图档位按钮可更大，允许更多文字描述。
- 战备页：偏出发清单，开始按钮是最强视觉锚点。
- 商店页：偏交易终端，价格、稀有度、附魔边框要比说明文字更快被看见。
- 仓库页：偏库存表，重复物品卡需要保持扫描效率。

## Visual Rules

- 页面导航使用扁平终端标签，不使用营销式大卡片或英雄区。
- 当前页面以琥珀边线和内发光表示，不能只靠颜色，需要同时有边框强度变化。
- 账号/密码 hook 使用低亮度输入框和禁用按钮，明确“预留但未上线”。
- 物品卡继续沿用稀有度边框和附魔辉光，避免在商店/仓库中失去战利构筑感。
- 移动端页面导航改为两列，优先保证文字不溢出和操作按钮不被压缩。

## Acceptance Criteria

- 玩家一眼能分辨当前在账号、地图、战备、商店或仓库中的哪个页面。
- UI 风格仍属于轻赛博废土地牢，而不是现代网页后台或商城首页。
- 局外面板不盖住局内核心 5x5 视野要求；局内 run 时只显示紧凑战备摘要。
