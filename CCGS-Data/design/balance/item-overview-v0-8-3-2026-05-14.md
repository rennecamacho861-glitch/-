## 当前构筑链提示

- 灼烧链：`tinder-vial` -> `soot-hook`，让目标更难躲闪。
- 中毒链：`poison-needle` 或 `smoke-needle` -> `venom-saw`，转成下一次近战伤害。
- 流血链：`barbed-line` 或 `thorn-plate` -> `blood-knot`，转成下一回合速度。
- 冻结链：`frost-nail` -> `frost-latch`，转成下一次受伤减免。
- 闪避链：`lens-thread` + `smoke-needle`，成功躲闪同时得到道具情报和反击中毒。
- 场外构筑链：`red-compass` 找高价值拾取点，`tripwire-spool` 和 `trap / bell-wire / caltrops` 控路并换取情报。
