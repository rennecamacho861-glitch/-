# v0.8.18 教程高亮与流程收束 Changelog

## 概要

本轮根据试玩反馈调整教程表现：推荐动作的框选更强、更动态；选择“需要新手教程”后不再混入旧版通用文字教程；战斗教学结束时先给出明确的迷宫目标提示，确认后才显示正式开局四选一。

## 规则/UX 同步

- `CCGS-Data/design/gdd/rulebook.md`
  - 明确脚本化教程期间不得穿插旧版通用文字教程。
  - 明确推荐动作必须有动态框选和非颜色文字标签。
  - 明确战斗教学完成后必须先显示“下面在整个迷宫中找到出口，带着道具逃离吧。”，玩家确认后再进入正式开局四选一。

- `CCGS-Data/design/ux/tutorial-onboarding.md`
  - 教程流程更新为：教程选择 -> 脚本化训练 -> 完成总结提示 -> 正式开局四选一。
  - 推荐动作高亮更新为动态框选、脉冲、角标。

- `CCGS-Data/design/ux/interaction-patterns.md`
  - `Scripted Tutorial Step` 记录禁止混入旧版通用教程文案。
  - `Coached Action Highlight` 记录 `选择此项` 标签和动态外框要求。

## 代码变更

- `src/sim/GameSimulation.ts`
  - 移除教程开始时额外插入的通用教程反馈，避免先弹文字教程再进战斗教学。
  - 战斗教学完成提示改为“下面在整个迷宫中找到出口，带着道具逃离吧。确认后进入开局选择。”

- `src/main.ts`
  - 脚本化教程结束后，若存在教程完成反馈，则隐藏开局四选一，直到玩家确认反馈。
  - 停用 `tutorialPreference === on` 后的旧版泛教程弹窗回退，避免流程混乱。

- `src/styles.css`
  - 推荐动作按钮新增动态外框、脉冲、光晕和 `选择此项` 角标。
  - 教程完成反馈窗口加强视觉权重。
  - `prefers-reduced-motion` 下关闭动态框选动画，保留静态强提示。
