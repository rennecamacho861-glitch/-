# Quick Design Spec: 敌人生态闭环与可读性

**Type**: Addition  
**System**: Enemy AI / Item System / HUD Feedback  
**GDD Reference**: `CCGS-Data/design/gdd/rulebook.md`  
**Date**: 2026-05-12

## Change Summary

v0.7 补齐敌人掉落、说服反馈、敌人战斗次数、随机姓名、寻物移动、敌人内战与战斗 AI 随机状态机。目标是让敌人不再只是被动巡逻单位，而是在迷宫中真实拾取、战斗、变强，并让玩家通过可读反馈理解这些变化。

## Motivation

当前原型已经具备敌人拾取、掉落、说服和内战的规则方向，但实现层仍存在断点：敌人死亡可能没有可感知掉落，成功说服没有明确情报反馈，敌人与敌人之间缺少可验证的后台战损，敌人命名和动作选择也过于模板化。v0.7 让“迷宫中其他人也在玩同一局”成为玩家能看见、能追踪、能利用的长线程压力。

## Design Delta

Current GDD says (`rulebook.md`, 第 12/13/14 章):

> 敌人会拾取道具节点，击败后按 35%/最多 2 件/5% 额外掉落规则保留装备状态。两个敌人相遇会自动结算内战，产生战损、遗物和胜者拾取成长。说服成功会停战并提供该敌人的属性数值或道具情况。

This spec changes that to:

敌人掉落必须有玩家可读结果：有可掉落装备时保底 1 件，其余继续按概率补充；没有可掉落装备时反馈“未发现可回收道具”。说服成功必须用确认式反馈展示本次获得的结构化情报。敌人新增 `combatCount`，记录真实发生过的战斗交换，并在照面面板直接可见。敌人以 seed 生成稳定混合姓名，移动状态加入 `seekLoot`，相邻可见敌人会自动内战并由胜者拾取败者遗物。

## New Rules / Values

- 敌人死亡掉落：
  - 候选装备为 `count > 0`、`charges > 0`、`durability > 0`、未破碎的当前持有装备。
  - 若候选装备数量大于 0，则至少掉落 1 件。
  - 保底之外，其余装备继续按每件 35% 独立检定；默认最多 2 件，5% 概率最多 3 件。
  - 掉落保留当前 `charges`、`durability`、`usedFlags`。
  - 玩家击败敌人后掉落自动加入背包，并生成 `loot-drop` 确认式反馈。
  - 若无候选装备，生成“未发现可回收道具”的 `loot-drop` 反馈。

- 说服反馈：
  - 说服成功后生成 `persuasion-intel` 确认式反馈。
  - 反馈正文只能列出本次新增的 `statExact` 或 `item` 情报。
  - 禁止恢复路线、接触、意图、态势、方向、性格等新文本情报。

- 敌人战斗次数：
  - `ActorState.combatCount` 初始为 0。
  - 玩家战斗中第一次动作回合发生时，该敌人 +1；同一场照面不重复增加。
  - 未见远程先手算作真实战斗，该敌人 +1。
  - 敌人内战双方都 +1。
  - 纯照面、巡逻、拾取、未交手前说服不增加。
  - 玩家照面面板直接显示敌人战斗次数。

- 随机姓名：
  - 敌人不再使用固定称号。
  - 地图生成时按 seed 为敌人生成稳定混合姓名，格式为 `姓 + 名字字 + -NN`，例如 `陈岚-07`。
  - 同一 seed 名称固定，不同 seed 可变化。

- 敌人移动与内战：
  - 敌人移动优先级：低血量恢复/后撤 > 追踪玩家 > 寻找最近未清空道具节点 > 巡逻。
  - `seekLoot` 状态下，敌人向可达的最近未清空 LootNode 单步移动。
  - 敌人移动与拾取后，若两个非中立、未败北敌人相邻且互相至少一方可见，则每对每回合最多自动内战一次。
  - 内战造成真实 HP 战损；若一方被击败，胜者按道具评分拾取败者遗物并受 4/5 件上限限制。
  - 玩家未看见时只写方向/声音级日志；玩家看见时可显示参与者、战损和拾取结果，但不打开玩家战斗面板。

- 敌人战斗 AI：
  - 战斗动作由 seed 决定的加权状态机选择。
  - 状态包括 `recover`、`rangedPressure`、`advantagePress`、`skirmish`、`guarded`、`default`。
  - 权重受生命、属性、优势、道具、视野影响，进攻、防御、躲闪都必须有合理出现率。
  - 所有随机选择使用当前 seed、turn、enemyId、round，保证测试可复现。

## Acceptance Criteria

- [ ] 击败有可掉落装备的敌人时，玩家至少获得 1 件装备，并弹出确认式掉落反馈。
- [ ] 击败无可掉落装备的敌人时，弹出“未发现可回收道具”反馈。
- [ ] 说服成功后生成 `persuasion-intel` 反馈，新增情报只包含属性数值或道具情况。
- [ ] 敌人初始 `combatCount === 0`，真实战斗后按规则增加，纯照面或未交手说服不增加。
- [ ] 同一 seed 下敌人姓名、移动、战斗动作和内战可复现。
- [ ] 敌人会朝未清空道具节点移动并拾取。
- [ ] 相邻可见敌人会触发内战，产生 HP 战损或击败，胜者可拾取遗物并受持有上限限制。
- [ ] No regression: 玩家移动、拾取、照面、严格情报格式、道具效果、边缘墙、远程视线不回归。
