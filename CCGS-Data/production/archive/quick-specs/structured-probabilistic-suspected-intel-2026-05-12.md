# Quick Design Spec: 情报只允许数值与道具

**Type**: Tweak  
**System**: Intel / Combat HUD  
**GDD Reference**: `CCGS-Data/design/gdd/rulebook.md`  
**Date**: 2026-05-12

## Change Summary

情报系统不再使用“硬守续战”“速度压迫”“读牌谈判”“暴露位置”“攻击方向”等任何现编态势文本。所有 `confirmed` 与 `suspected` 情报都只能是两种字段格式：`属性 = 数值` 或 `拥有某道具 / 未见道具`。推测情报按玩家智力得到可信率，再由 seed 判定该条推测是否读取真实状态；若未命中，则生成同格式假情报。

## New Rules / Values

- 所有情报只允许两类显示：
  - `statExact`：五项属性之一的具体数值，例如 `速度 = 5`。
  - `item`：某个道具，例如 `拥有手枪`。
- `suspected` 必须带 `confidence`。
- 可信率由玩家智力决定，MVP 使用 `45% + 智力 * 8%`，封顶 85%。
- 命中可信率时，显示真实属性值或真实持有道具。
- 未命中可信率时，显示随机属性值或随机道具；格式仍与真情报一致。
- UI 不直接显示真假，只显示“推测 X%”。

## Acceptance Criteria

- [ ] HUD 不再出现 `硬守续战`、`速度压迫`、`读牌谈判`、`攻击方向` 等任何非数值/非道具情报文本。
- [ ] 推测情报显示为 `推测 69% 速度 = 5` 或 `推测 69% 拥有绷带`。
- [ ] 道具推测仍可 hover 查看该道具说明和反制空间。
- [ ] 自动化测试覆盖推测情报格式与可信率字段。
