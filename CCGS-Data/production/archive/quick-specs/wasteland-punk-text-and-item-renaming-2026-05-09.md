# Quick Design Spec: 废土朋克文本与道具命名

**Type**: Tweak  
**System**: Narrative Text / Item System / HUD  
**GDD Reference**: `CCGS-Data/design/gdd/rulebook.md`  
**Date**: 2026-05-09  

## Change Summary

将《照面之时》的默认背景世界观从抽象黑暗迷宫调整为废土朋克：玩家在封存地堡、废墟管廊和旧城回收区中搜打撤。此次只改变世界观、文本调性、道具显示名和描述，不改变任何道具 ID、数值、触发时机、掉落、敌人成长或战斗公式。

## Motivation

当前文本偏“黑暗迷宫 + 赌博隐喻”，能表达短促博弈，但缺少可持续扩展的物件质感。废土朋克能让低武近战、稀缺枪弹、拾荒构筑、红光报警、毒圈压迫和敌人成长自然统一起来，也能让道具名更有可辨识的材料和来源。

## Design Delta

当前 GDD 的核心体验是：5-10 分钟俯视角黑暗迷宫搜打撤，玩家在有限视野中获取道具、判断撤离，并在照面时进行短促博弈。

本规格将文本表达改为：

玩家是旧城废墟中的拾荒者，进入一座被封存的地下回收区。这里的可用物来自报废车辆、断电设施、旧军械、灰市药剂和自制报警装置。迷宫仍是俯视角格子地图，但文案中称为“废墟管廊 / 封存区 / 地堡回收区”；道具节点称为“拾荒点 / 货箱 / 废料堆”；危险度称为“热度 / 警戒”；撤离点称为“闸门 / 撤离井 / 外环出口”。

## New Rules / Values

### 世界观基调

- 核心背景：大断电后的旧城地下回收区，资源稀缺、设备拼修、远程武器极少，近身武器和临场小道具更常见。
- 视觉词汇：锈蚀金属、红色警示灯、裂镜、油污、旧弹壳、胎胶、铆钉、风机、断电闸门、回收箱。
- 赌博体验保留，但表达为“赌命局 / 下注一口气 / 拿命押这步”，不使用现代赌场豪华意象。
- “照面”保留为核心术语，在废土语境中表示双方在灯光、枪口或拐角处同时暴露的瞬间。

### 文本语气

- 短句、冷硬、物件感强。
- UI 文本优先使用动作结果和可验证信息，不写长段背景说明。
- 战斗日志强调方向、声音、光源、弹药、伤口和设备状态。
- 禁止把道具写成魔法、玄幻或高科技超能力；所有效果都要像废土手工装置、旧世界残件或灰市药剂。

### 命名规则

- `ItemId` 保持不变，避免破坏存档、测试和代码端口。
- `name` 与 `description` 改为废土朋克显示文本。
- 道具效果、稀有度、充能、反制空间全部沿用当前规则。
- 若后续新增道具，名称优先包含材料、来源或使用方式，例如“胎胶”“铆钉”“旧弹壳”“油烟”“裂镜”。

## Acceptance Criteria

- [ ] 游戏运行时不再把默认场景称为抽象黑暗迷宫，而称为废土管廊、封存区或地堡回收区。
- [ ] 所有玩家可见道具名按本表替换，`ItemId` 不变。
- [ ] 所有道具描述保留原规则效果、数值、稀有度、充能和反制空间。
- [ ] 日志文本能体现方向、红光、弹药、油烟、旧铁、伤口或回收物等废土元素。
- [ ] HUD 不增加长篇说明，不遮挡俯视角格子地图。
- [ ] `npm test` 和 `npm run build` 在文本实装后通过。
- [ ] 无回归：拾取、敌人拾取、掉落保留状态、手枪弹药、长刀投掷、陷阱和眼镜效果不改变。
