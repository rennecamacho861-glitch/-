# v0.5 道具构筑与敌人成长 Proposal

日期：2026-05-09  
规则真源：`CCGS-Data/design/gdd/rulebook.md`  
架构真源：`CCGS-Data/project-docs/architecture/system-framework.md`

## 需求分析

本次变更回应 v0.4 原型中的三个问题：

- 主动搜索不提供有意义决策，改为踩点即触发三选一。
- 屏息/等待没有实际收益，先移除，避免玩家误以为这是有效策略。
- 敌人应在局内与玩家争夺资源，通过随机属性和拾取道具逐步形成威胁，而不是靠固定种类标签。

## 设计方案

- 将搜索点替换为 `LootNode`，每个节点提供 3 件不同道具候选。
- 玩家进入节点格后弹出三选一；选择或跳过不额外推进回合，节点清空。
- 敌人移动到节点时自动选 1 件并清空节点，普通敌人持有上限 4 件，精英 5 件。
- 击败敌人后按 35% 独立检定掉落身上装备，最多 2 件，5% 概率额外 1 件，并保留弹药/充能/耐久。
- 道具池新增 30 件小收益道具，分为伤害、生存、信息三类，保持低武近战核心。

## 影响评估

| 系统 | 影响 |
|---|---|
| Map & Exploration | 搜索按钮移除，踩点触发拾取选择 |
| Item System | 道具定义扩展，新增三选一和实例状态 |
| Enemy AI | 移除固定敌人类型，AI 根据属性与道具推导行为并拾取成长 |
| Encounter Combat | 手枪 5 发、长刀可投掷、每轮主动道具使用限制 |
| HUD & Combat UI | 新增拾取弹窗，移除搜索/屏息按钮 |
| QA | 需要新增 LootNode、敌人拾取、掉落保留状态测试 |

## 验收标准

- 玩家踩到节点能三选一，选择不额外推进回合。
- 敌人能拾取节点并清空节点。
- 手枪默认 5 发，弹药消耗和掉落保留剩余弹药。
- 敌人行为不依赖固定 `archetype`。
- `npm test` 和 `npm run build` 通过。
