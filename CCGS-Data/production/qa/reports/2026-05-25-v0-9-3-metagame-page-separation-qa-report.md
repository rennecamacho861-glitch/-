# v0.9.3 局外大厅页面分区 QA 报告

日期：2026-05-25  
范围：局外大厅 DOM HUD、页面导航、账号 hook、商店/仓库/战备物品 tooltip  
结论：PASS WITH NOTES

## 验收点

- 局外大厅不再把账号、地图、战备、商店、仓库全部展开在同一页面。
- 页面导航可切换 `账号 / 地图 / 战备 / 商店 / 仓库`。
- 顶部摘要保留金币、地图、入场费、战备值和仓库数量。
- 账号页包含 `data-auth-hook` 和 `data-auth-field`，并保持登录/注册按钮禁用，避免误导玩家。
- 商店、仓库、战备物品卡继续支持 hover/focus tooltip。
- 同页操作保留滚动位置；跨页面切换不继承旧滚动位置。

- `npm test`：通过，132/132。

## 手动检查建议

- 在浏览器中逐页切换账号、地图、战备、商店、仓库，确认当前页面高亮清楚。
- 在商店页滚动到较低位置后购买物品，确认不会被拉回顶部。
- 在仓库页滚动到较低位置后带入/出售物品，确认不会被拉回顶部。
- 移动端宽度下检查导航两列布局和账号输入框不溢出。

## 残留风险

- 本轮未使用浏览器截图保存视觉证据；建议后续发布前补桌面和移动端截图。
- 账号 hook 只有 DOM 标记，没有真实认证端口和存档同步策略；后续接入时需要独立 Story。
