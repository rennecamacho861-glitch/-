# Grid Dungeon Procedural Audio Deprecation

Date: 2026-05-13

The WAV files in this directory root were generated by the previous procedural placeholder pipeline. They are now deprecated and must be treated as reference-only.

## Current Source Policy

- Approved production audio must come from model-generated raw sound effects or licensed/recorded Foley sources.
- Do not integrate the root `manifest.json` into Phaser runtime playback as final audio.
- Do not use the procedural WAV files as substitutes for model audio.
- The next approved runtime manifest is expected to be `manifest.model-generated.json`, produced only after the model-render import gate passes.

## Model Audio Flow

1. Generate or refresh requests:
   `node scripts/audio/prepare-grid-dungeon-audio-model-prompts.mjs`
2. Render WAV files with an audio/sound-effect generation model.
3. Place rendered files in:
   `CCGS-Data/design/audio/source/grid-dungeon/model-renders/iter03/`
4. Validate and import:
   `node scripts/audio/import-grid-dungeon-model-audio.mjs`
5. Runtime integration may use:
   `public/assets/audio/grid-dungeon/model/`
   and `public/assets/audio/grid-dungeon/manifest.model-generated.json`

## Explicitly Forbidden Style

- 8-bit / chiptune
- synthetic oscillator tones
- sci-fi UI bleeps
- laser-like electronic hits
- EDM pulses or melodic loops
- cartoon button sounds
